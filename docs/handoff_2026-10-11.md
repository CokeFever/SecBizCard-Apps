## 🔴 web editor 白屏急救(重開 session 必讀,根因+修法)
### 症狀
ixo.app/editor(以及 /、/guide 全站)白屏。HTTP 200、資源都 200、CSP 看似正常,但瀏覽器 runtime 掛掉。
### 根因(實際從產物看到,非猜測)
10-10 的 L2 `npm audit fix` 把 **Nuxt 4.3.0 → 4.6.0**。Nuxt 4.6 新增**可執行 inline**
`<script type="importmap">{"imports":{"#entry":"/_nuxt/<hash>.js"}}</script>`,被嚴格 CSP
(`script-src 'self'` 無 unsafe-inline)擋 → `#entry` 解析失敗 → 全站白屏。build 成功、curl 健康,
因為 CSP 只在瀏覽器 runtime 擋 inline。
### 修法(正解,commit aa5210f,已上線)
`website/nuxt.config.ts` 加 **`experimental: { entryImportMap: false }`** → entry 回到
`<script type="module" src=...>`,嚴格 CSP 照舊能用。**Nuxt 維持 4.6(沒 revert、沒放棄 L2)、
CSP 零改動(沒加 unsafe-inline)** —— user 明確要求「真正修好、不走逃生門」。importmap 不能用 src
外部化(HTML 規範禁止),所以只能關 feature。headless Chrome 在嚴格 CSP 下實測 /editor、/、/guide
hydration + 零 CSP 違規。
### 教訓(已寫進 `.kiro/steering/web-editor-csp.md`)
**凡動 Nuxt 版本或 build 產物,必做「嚴格 CSP 下的 headless runtime hydration 實測」**,build 綠燈
+ curl 健康都不夠(白屏兩次都這樣漏掉)。用 `website/scripts/serve-with-csp.mjs` + puppeteer/playwright。
