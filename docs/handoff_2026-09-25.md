## What shipped this session

### 1. Paid subscription (Plus / Pro via RevenueCat)
- Plus/Pro tiers, more cloud OCR scans on paid tiers, free tier stays free.
- Subscription state machine + entitlement resolution on the backend (expiry
  math handles cancel = stop-renew-keep-until-expiry, refund = immediate).
- Android RTDN (Pub/Sub `revenuecat-play-notifications`) + iOS App Store Server
  Notifications wired.
- **Restore trusts the backend**, not the stores: `_runRestore` re-syncs and
  shows the backend tier; no optimistic store tier. Timeout fallback in place.
- Cancelled-status display + syncing lock in OCR settings.

### 2. Cross-account contact leakage — fixed
- Root cause: local DB wasn't wiped on sign-out, so a second account on the same
  device saw the first account's imported contacts.
- Fix (option A): `signOut` now wipes the local DB
  (`DatabaseHelper.instance.deleteAllData()`). Data is restorable from Drive.
- Drawer logout now **warns before wiping**, with a stronger warning when there
  are unbacked-up local changes (`drawerLogoutWipeNote` /
  `drawerLogoutUnbackedWarning`, 5 locales).

### 3. QR exchange deep-link / landing page — end to end
- **assetlinks.json** on `ixo.app` root = the 3 live signing fingerprints
  (root path covered).
- **iOS `secbizcard://` scheme** added (Info.plist) so the landing page "Open"
  button actually opens the app; same-domain Universal Link won't hand off when
  already on that domain. Desktop hides the Open button.
- **Deferred deep-link continuation** wired: `MainScreen._resumePendingHandshake`
  + `DeepLinkService.awaitPendingSession` (precise short-poll ≤3s — instant for
  app↔app, only waits on genuine first-launch-after-install).
- **Fingerprint deferred-link REMOVED** (unreliable + privacy-questionable):
  deleted landing-page code and the 2 backend Cloud Functions
  (`savePendingSession` / `getPendingSession`). Kept clipboard hand-off (iOS) +
  install referrer (Android) + Universal/App Link.
- **Landing page** (`SecBizCard/website/public/flutter/index.html`): 5-locale
  i18n (en/zh-Hant/zh-Hans/ja/ko, fallback en), centered logo, bottom site-footer
  matching ixo.app, `100svh` fix so footer shows without scrolling.

### 4. Legal / store
- Privacy Policy + EULA updated with subscription clauses (live on ixo.app).
- App Privacy (iOS) + Data Safety (Android) labels filled (Purchases + Device ID).

### 5. Docs tidy (commit `a4685a1`)
- `docs/` 28 → 16 files. Dropped stale release copies, dated handoffs, junk key
